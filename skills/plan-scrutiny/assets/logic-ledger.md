## How an entry is marked

- **User decided**: the user gave the decision and the reason.
- **AI proposed, user chose, reason: ...**: the AI offered options, the user picked one and gave a reason. Without the reason the row stays open.
- **Assumption**: no evidence yet. Say who will confirm it and by when.
- **Fixed before we started**: decided elsewhere; name where. Still needs a reason the user can say out loud.
